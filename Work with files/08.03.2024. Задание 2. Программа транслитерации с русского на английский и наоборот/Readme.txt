* Данная версия не поддерживает загрузку пользовательских словарей, только стандартный Dictionary.json

Задача: написать программу транслитерации с русского на
английский и наоборот. Данные для транслитерации
должны браться из одного файла и записываться в другой файл. 
Направление перевода определяется через главное меню программы.

По желанию, добавить возможность выхода по кнопке 0 и перехват ошибок,
чтобы пользователь не мог вводить буквы, знаки и спец. символы, а также
разбить программу на несколько файлов для более удобного и читабельного кода.
Плюс, также по желанию, сделать проверку на наличие исходного файла со словарём.
