Пользователь вводит названия файлов, например IN.txt и OUT.txt, названия файлов могут быть произвольными.
После завершения ввода, программа должна записать в итоговый файл, назовём его FINAL.txt символы, которые
есть во всех перечисленных файлах и которые различны для всех перечисленных файлов.
После того как пользователь введёт слово quit, программа завершает работу.
Также, необходимо сделать игнорирование пробелов и возможность ввода названий файлов в разном регистре.
Для повышения удобства и читабельности кода, желательно разделить программу на несколько файлов.

main.py - основной файл программы, куда стекаются все ссылки.
main_menu.py - файл с главным меню программы.
main_operations.py - обвязка условий сравнения и вывод на дозапись в файл FINAL.txt (обвязка и основной функционал).

IN.txt - первый файл с данными.
OUT.txt - второй файл с данными.
FINAL.txt - файл с выходными данными. Изначально пуст. Наполняется после запуска программы.
