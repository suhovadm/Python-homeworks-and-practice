*** КАК КОМПИЛИТЬ КОД В PyCharm-e в .exe-шник ?

КОРОТКИЙ ВАРИАНТ:
pyinstaller --onefile --clean --noconfirm --strip your_script.py

БОЛЕЕ ДЛИННЫЙ ВАРИАНТ:
pyinstaller --onefile --clean --noconfirm --strip --name MyProgram --icon icon.ico --log-level=WARN --windowed --exclude-module tests --exclude-module unittest --exclude-module pydoc your_script.py

ЧТО ЗДЕСЬ ПРОИСХОДИТ?

--onefile, или -F // сборка в единый .exe-шник

--clean // удаляет кэш

--noconfirm // автоматически отвечает "yes" на все вопросы во время сборки проекта в .exe-шник

--strip // удаляет дебаг-символы из бинарников (реально работает в Linux/macOS, в Windows почти ни на что не влияет)

--name MyProgram, или -n MyProgram // как будет называться наша прога

--icon icon.ico, или -i icon.ico // добавляет иконку к .exe-файлу, если она есть

--log-level=WARN // этот параметр регулирует уровень логирования сборки PyInstaller. Обычно ставят либо INFO, либо WARN
TRACE // максимально подробный
DEBUG // только отладочная информация
INFO // обычные сообщения
WARN // только предупреждения
ERROR // только ошибки
FATAL // критические ошибки

--windowed, или -w, или --noconsole // запускает программу без консольного окна, на размер файла не влияет.
Это нужно прописывать, только когда мы пишем ГУИ-приложение.

--upx-dir // включает сжатие бинарников через UPX. UPX перепаковывает exe и DLL, уменьшая их размер.
Иногда после упаковки некоторые DLL могут работать некорректно или вовсе не загружаться.
Особенно часто это происходит, когда мы работаем с библиотеками Qt, numpy, PySide, или системными библиотеками Windows.
Некоторые антивирусы могут ругаться на переупакованный файл с использованием UPX, потому что они скрывают настоящий код.
Вследствие чего помечают такие файлы как вредоносные, так как многие из них используют UPX для упаковки и сокрытия кода.

--noupx // запрещает PyInstaller использовать UPX, даже если он установлен в системе. То есть никакого сжатия.
Как итог: .exe-шник больше по размеру, зато более стабильный запуск.

--exclude-module // запрещает PyInstaller добавлять указанные модули (выигрыш в пару сотен килобайт)

--add-data // добавляет файлы в сборку .exe-файла (картинки, json, txt и т.д.)
На Windows: --add-data "file.txt;." // На Linux/Mac: --add-data "file.txt:."

*** После сборки .exe находится в папке dist/ там же, где и основной .py-файл с проектом. 
*** Если pyinstaller (вдруг!) не установлен, то ставится он вот так: pip install pyinstaller
