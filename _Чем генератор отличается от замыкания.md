Чем генератор отличается от замыкания?  
- Замыкание хранит переменные.  
- Генератор хранит позицию выполнения + локальные перменные.  

Например, задача выдавать числа от 0 до n-1 по одному:  

Вариант 1 - через генератор:  
Что здесь происходит?  
Python автоматически сохраняет:  
- текущий i,  
- место выполнения,  
- yield "замораживает" функцию.  
Состояние хранится автоматически.  

```
def gen_counter(n):
    for i in range(n):
        yield i


g = gen_counter(3)

print(next(g))  # 0
print(next(g))  # 1
print(next(g))  # 2
```

Вариант 2 - через замыкание:  
Что мы делаем?  
i хранится во внешней функции.  
внутренняя функция замыкает переменную i.  
состояние (i) сохраняется между вызовами.  
Мы вручную управляем состоянием.  

def make_counter(n):

    i = 0

    def counter():
        nonlocal i
        if i < n:
            value = i
            i += 1
            return value
        else:
            return None

    return counter

c = make_counter(3) # <-- Растягиваем счётчик.  
Т.е. сколько надо вывести ДО None! В нашем случае 3 штуки. 0, 1, 2, потом выведет None.  

print(c()) # 0  
print(c()) # 1  
print(c()) # 2  
print(c()) # None

Главные отличия:  

В замыканиях мы сами храним i // В генераторах Python хранит i  
В замыканиях нужен nonlocal // В генераторах ничего не нужно  
В замыканиях возвращаем функцию // В генераторах возвращаем генератор  
В замыканиях логика сложнее // В генераторах логика проще  

Замыкание - это функция с памятью о внешних переменных.  
Генератор - это функция, которая умеет ставить выполнение на паузу.
