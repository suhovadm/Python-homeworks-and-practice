Чем итератор отличается от генератора ?  

Итератор ( iterator ).  

Итератор - это объект, который:  
1. Имеет метод __iter__() - возвращает сам себя.  
2. Имеет метод __next__() - возвращает следующий элемент или вызывает StopIteration.  

Пример итератора:  

```
class MyIterator:
    def __init__(self, limit):
        self.limit = limit
        self.current = 0

    def __iter__(self):
        return self

    def __next__(self):
        if self.current < self.limit:
            self.current += 1
            return self.current
        else:
            raise StopIteration


it = MyIterator(3)

for x in it:
    print(x)
```

Итераторы нужно реализовывать вручную, прописывая логику.  

________________________________________________________________________________________

Генератор ( generator ).  
Генератор - это удобный способ создать итератор.  

Он автоматически:  
- реализует __iter__() и __next__()  
- управляет состоянием.  
Создаётся с помощью yield.  

return - возвращает значение и завершает функцию.  
yield - возвращает значение и запоминает состояние, чтобы продолжить позже.  
yield превращает функцию в генератор, который:  
- выдаёт значения по одному,  
- не хранит всё в памяти сразу.  

```
def my_generator(limit):

    current = 0

    while current < limit:
        current += 1
        yield current


gen = my_generator(3)

for x in gen:
    print(x)
```

Здесь Python сам делает из функции итератор.  

___ Главное отличие. ___  

Итератор — создаём класс и сами реализуем __iter__() и __next__().  

Генератор — пишем обычную функцию с yield, а Python сам управляет состоянием и итерацией.  

Главная идея:  
Генератор — это частный случай итератора.  
Любой генератор является итератором, но не любой итератор — генератором.  
 
Когда использовать?  

Генератор — когда нужна простая ленивая последовательность значений.  

Итератор-класс — когда нужна более сложная логика и полный контроль над состоянием.  

___ Или ещё проще. ___  

Итератор — пишем класс и сами управляем перебором элементов.  

Генератор — пишем функцию с yield, а Python делает остальное.  

Когда использовать?  

Генератор — когда нужна простая последовательность значений.  

Итератор — когда нужна более сложная логика.
