Чем итератор отличается от генератора ?  

Итератор ( iterator ).  

Итератор - это объект, который:  
1. Имеет метод __iter__() - возвращает сам себя.  
2. Имеет метод __next__() - возвращает следующий элемент или вызывает StopIteration.  

Пример собственного итератора:  

```
class MyIterator:
    def __init__(self, limit):
        self.limit = limit
        self.current = 0

    def __iter__(self):
        return self

    def __next__(self):
        if self.current < self.limit:
            self.current += 1
            return self.current
        else:
            raise StopIteration


it = MyIterator(3)

for x in it:
    print(x)
```

Итераторы нужно реализовывать вручную, прописывая логику.  

Генератор ( generator ).  
Генератор - это удобный способ создать итератор.  

Он автоматически:  
- реализует __iter__() и __next__()  
- управляет состоянием.  
Создаётся с помощью yield.  

return - возвращает значение и завершает функцию.  
yield - возвращает значение и запоминает состояние, чтобы продолжить позже.  
yield превращает функцию в генератор, который:  
- выдаёт значения по одному,  
- не хранит всё в памяти сразу.  

```
def my_generator(limit):

    current = 0

    while current < limit:
        current += 1
        yield current


gen = my_generator(3)

for x in gen:
    print(x)
```

Здесь Python сам делает из функции итератор.  

Главное отличие:  

Итератор:                             Генератор:  
Нужно писать класс                    Пишется как функция  
Реализуешь __next__() вручную         Используешь yield  
Более громоздкий                      Более простой и читаемый  
Полный контроль                       Удобство и компактность  

Ключевая идея:  
Генератор - это частный случай итератора.  
Любой генератор - итератор.  
Но не любой итератор - генератор.  

Когда использовать?  

Генераторы когда:  
- нужна простота,  
- обрабатываем большие данные (ленивая загрузка),  
- пишем последовательности.  

Итераторы (классы), когда:  
- нужна сложная логика состояния,  
- нужен полный контроль над поведением.
