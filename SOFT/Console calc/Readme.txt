Консольный калькулятор. Несколько вариантов.

---------------------------------------------------------------------------------------
#1.
Первая версия - максимально простой кальк из 6 команд + перехват ошибок.
Всё сделано в одном файле.
Ввод цифр сделан через float, у каждого float-a есть свой бесконечный цикл while
внутри которого сделан перехват ошибок try / except на тему неверного ввода символов.
Это сделано для того, чтобы пользователь в переменные a и b мог вводить только целые
и дробные числа. Также, в цикл while обернут и сам скрипт. Это сделано, чтобы не 
перезапускать программу вручную каждый раз когда она завершается.
Всего, кальк поддерживает 6 команд:
( + ) сложение,
( - ) вычитание,
( * ) умножение,
( ** ) возведение в степень,
( / ) деление,
( // ) целочисленное деление (деление без остатка).
Плюс, в поле для ввода символа можно ввести quit, или exit для выхода из программы.
Данные команды прерывают основной цикл while брейком и тем самым завершают его.
Также, сделан небольшой обработчик в виде обычного else, если пользователь ошибся
при вводе символа.
---------------------------------------------------------------------------------------
#2.
Вторая версия - более сложная версия консольного калькулятора.

Те же 6 команд + перехват ошибок, если пользователь
выбрал не верный пункт меню, или ввёл буквы вместо цифр + игнорирование пробелов.

1. Сложение.
2. Вычитание.
3. Умножение.
4. Возведение в степень.
5. Деление.
6. Деление без остатка.
+ Есть возможность выхода по нажатию на 0.

В данном случае, кальк обыгран через функции, главное меню и операторы ветвлений if / elif.
Вся программа разделена на 3 файла для более удобного и читаемого кода.
