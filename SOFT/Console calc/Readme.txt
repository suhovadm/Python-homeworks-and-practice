Консольный калькулятор. Несколько вариантов.

---------------------------------------------------------------------------------------
#1.
Первая версия - максимально простой кальк из 6 команд + перехват ошибок.
Всё сделано в одном файле.
Ввод цифр сделан через float, у каждого float-a есть свой бесконечный цикл while
внутри которого сделан перехват ошибок try / except на тему неверного ввода символов.
Это сделано для того, чтобы пользователь в переменные a и b мог вводить только целые
и дробные числа. Также, весь скрипт обёрнут в цикл while, чтобы не перезапускать
программу вручную каждый раз когда она завершается.
Всего, кальк поддерживает 6 команд:
( + ) сложение,
( - ) вычетание,
( * ) умножение,
( ** ) возведение в степень,
( / ) деление,
( // ) целочисленное деление.
Плюс, в поле для ввода символа можно ввести quit, или exit для выхода из программы.
Данные команды прерывают основной цикл while брейком и тем самым завершают его.
Также, сделан небольшой обработчик в виде обычного else, если пользователь ошибся
при вводе символа.
