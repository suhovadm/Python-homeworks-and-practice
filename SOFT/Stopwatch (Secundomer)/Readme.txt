Несколько вариантов реализации секундомера.
Простой выполнен с помощью библиотеки time, сложный с помощью библиотек time, threading и sys.
Компилировать их особого смысла нет, так как они будут занимать 6+ мегабайт.
Однако, данные скрипты можно использовать в каком-нибудь проекте где жизненно необходим секундомер.
