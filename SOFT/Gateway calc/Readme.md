Что это такое?  

Это калькулятор шлюзов, написанный на Python.  
Достаточно ввести IP-адрес и маску подсети (полностью, или по CIDR-у) и он покажет:  

IP, маску, префикс, сеть, broadcast, первый доступный адрес сети,  
последний доступный адрес сети и общее количество доступных адресов в сети.  

Прога крутится в бесконечном цикле, ничего перезапускать не нужно.  

Поддерживает историю на 100 последних введённых команд,  
а также выход по командам exit, quit, или комбинации Ctrl + C.  
Также, поддерживается очистка экрана по командам cls, или clear.  
_____________________________________________________________________________________________________________________  

Для удобства, исходный код разбит на 5 файлов:  

1. main.py - главный файл программы. Связывает все модули между собой.  
2. config.py - настройки кодировки и лимиты истории команд.  
3. console_utils.py - здесь живут очистка экрана, ввод данных и обработка команд - history, cls, clear, exit и quit.  
4. history.py - очередь истории и функции для добавления и отображения команд.  
5. subnet_calculator.py - здесь живёт проверка ipv4, маска подсети и расчёт параметров сети.  
_____________________________________________________________________________________________________________________  

Для удобства есть готовая версия, собранная в .exe-шник.
