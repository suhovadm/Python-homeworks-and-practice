1.  
Архитектура проекта.  
Создаём папку PUNK_RADIO_PLAYER со следующей структурой:  

PUNK_RADIO_PLAYER/  
│  
├── clipboard.py  
├── config.py  
├── footer.py  
├── header.py  
├── icy_metadata.py  
├── logo.py  
├── main.py  
├── metadata.py  
├── metadata_updater.py  
├── now_playing.py  
├── playback_controls.py  
├── player.py  
├── requirements.txt  
├── station_selector.py  
├── stations.py  
├── volume_control.py  
│  
├── assets/  
│   └── icon.ico  

* assets - это отдельная папка внутри папки PUNK_RADIO_PLAYER  
* Внутри папки assets должна лежать иконка. Название иконки желательно icon.ico.  
* Иконка должна быть в формате .ico, размером 256x256 пикселей, глубина цвета x32.  

* Где можно скатать иконки?  
https://www.flaticon.com/  
https://icons8.com/  
https://www.svgrepo.com/  

Конвертер из JPG/PNG --> ICO  
https://convertio.co/ru/png-ico/  

2.  
Установка необходимых компонентов.  
Сначала установим VLC Media Player для Windows 10 с официального сайта:  

https://get.videolan.org/vlc/3.0.24/win64/vlc-3.0.24-win64.exe  

Он будет выступать в роли аудиодвижка.  
Без него, к сожалению, наш радио-проигрыватель работать не будет.  

* Если у нас Windows x64, то Python x64 и VLC тоже x64 вобязон! Разрядность отличаться не должна!  

3.  
Создаём виртуальное окружение:  

py -3.11 -m venv .venv  

// venv .venv обязательно ЧЕРЕЗ пробел, иначе выдаст ошибку!  

4.  
Активируем его:  

.venv\Scripts\activate  

5.  
Создём requirements.txt:  

customtkinter  
python-vlc  
requests  

* Это список дополнительных Питоновских библиотек, которые нужны для работы нашей программы.  

customtkinter // Красивый интерфейс программы.  
python-vlc // Управление аудиодвижком VLC.  
requests // Получение данных из интернет-радио.  

6.  
Устанавливаем зависимости:  

python -m pip install --upgrade pip  
pip install -r requirements.txt  

7.  
Установим библиотеку customtkinter. Этот шаг абсолютно опционален, его можно пропустить.  
Он нужен только на тот случай, если по какой-то причине customtkinter не подтянулся через requirements.txt  

cd punk_radio_player  
python -m pip install customtkinter  

Эта библиотека нужна для того, чтобы делать красивые окна программ с кнопками, ползунками, тёмной/светлой  
темами и панельками меню, а также выпадающими списками.  

8.  
Теперь сделаем 2 небольшие проверки.  

* Первая. Проверим, что необходимые библиотеки установлены.  

pip show python-vlc  

Если видим вот такой вывод, значит всё гуд.  

Name: python-vlc  
Version: 3.0.21203  
Summary: VLC bindings for python.  
Home-page: https://wiki.videolan.org/PythonBinding  
Author:  
Author-email: Olivier Aubert <contact@olivieraubert.net>  
License: LGPL-2.1+  
Location: C:\Users\Administrator\PycharmProjects\newProjectMarth2025\venv\Lib\site-packages  
Requires:  
Required-by:  

* И вторая. Убедимся, что VLC-движок подключён и работает.  

python -c "import vlc; print('VLC version:', vlc.libvlc_get_version().decode()); print('VLC успешно подключён!')"  
 
В выводе должно быть вот так:  

VLC version: 3.0.24 Vetinari  
VLC успешно подключён!
